# Project Genesis — City Repository

The independent repository for **Genesis**, a founder-directed city on the Lakeland map in **Cities: Skylines II**. This project is separate from the historical Minecraft/Meridian world.

## Website
- `index.html` — accessible, responsive municipal landing page, with no external libraries or trackers.
- The repository is **private**. Publishing the site will require a separate hosting or GitHub Pages decision.
- All website content is roleplay/game-world information. No live-game integration is implied.

## Project records
- GEN-INF-001 — high-voltage crossing and related line work: **construction complete, commissioning pending**.
- GEN-INF-002 — transformer: **installed, switched off, commissioning pending**.
- Finalized report and original five Founder screenshots are preserved in the Founder's designated Google Drive project archive; this repository does not duplicate private images without instruction.
- Active project register is an independent Genesis Airtable base. Actual costs and treasury snapshots are distinct.

## Project conventions
- `GEN-ADM-###`: administration
- `GEN-AGT-###`: AI-agent identity (Mayor Elias Mercer: GEN-AGT-001)
- `GEN-INF-###`: infrastructure
- `GEN-DEV-###`: future development
- `GEN-TRY-###`: treasury snapshots

## Governance and accuracy
The Founder directs construction and major approvals; the Mayor advises and maintains authorized records. Fictional outside contractors are **not** AI agents. Distinguish **proposed**, **approved**, **construction complete**, **commissioned**, and **operational**. Do not publish unverified financial figures or imply an unbuilt project is finished.

## Updating the site
Edit `index.html` on `main`. Keep project milestone statements evidence-based and mark any future proposal as such.
